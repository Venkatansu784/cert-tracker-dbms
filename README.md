# Corporate Compliance & Certification Tracker (DBMS)

An enterprise-grade full-stack database management system designed to automate certification lifecycle management and ensure workforce readiness.

## Tech Stack
- **Frontend:** HTML5, CSS3 (Dark Theme), JavaScript (ES6+)
- **Backend:** Node.js, Express.js REST API
- **Database:** PostgreSQL (pgAdmin) with automated PL/pgSQL triggers

## Features
- **Role-Based Authorization:** Secure authentication interface for HR and Administrators.
- **Dynamic Metrics:** Real-time database aggregation for valid, expiring, and expired certifications.
- **Automated Compliance Triggers:** Database-level trigger calculating compliance status based on expiration dates.
- **Full CRUD Integration:** Direct record insertion and deletion linked with PostgreSQL relations.
