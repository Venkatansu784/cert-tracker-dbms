# Corporate Compliance & Certification Tracker (DBMS)

An enterprise-grade database management system designed to automate certification lifecycle management and ensure workforce readiness. 

## Features
- **Role-Based Access:** Secure login portal for HR and Administrators.
- **Dynamic Metrics:** Real-time calculation of valid, expiring, and expired certifications.
- **Dark Mode UI:** Sleek, responsive, high-contrast dashboard interface.
- **Data Entry Matrix:** Streamlined CRUD forms for database insertion.

*Note: Currently deployed as a frontend prototype utilizing client-side LocalStorage pending backend database integration.*
